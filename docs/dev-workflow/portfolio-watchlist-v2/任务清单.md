## 1. 全局执行规则

- 每个业务逻辑任务遵循 RED → GREEN → REFACTOR，先写失败测试。
- 每个任务最多约 5 个主要文件；发现超出时先拆任务，不扩大范围。
- Python 类和方法、TypeScript 导出组件和业务 Hook 必须有清晰中文职责注释。
- 财务计算只使用 `Decimal`，API 金额使用十进制字符串。
- 每个任务完成后执行目标测试；每个检查点执行全量 lint、类型检查、测试和构建。
- 旧 Streamlit 文件、旧 Compose、SQLite 数据和 `.idea/` 在开发阶段不修改。
- 依赖、数据源或生产环境与规格不一致时，先更新规格并请求确认。
- Git 提交只在用户明确授权后执行；即使任务完成，也不会自动提交。
