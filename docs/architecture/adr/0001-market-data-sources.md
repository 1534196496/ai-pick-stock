# ADR-0001：一期免费行情与基金净值数据源

- 状态：已接受
- 决策日期：2026-08-24
- 实测环境：Google Cloud 当前服务器，UTC
- 适用范围：A 股、中国公募基金主数据、股票最新价、基金官方单位净值、可选估算净值

## 背景

页面请求只允许读取本地 PostgreSQL，外部数据由 Worker 异步同步。免费页面接口没有稳定 SLA，字段和网络路由可能变化，因此必须先经过 Provider 边界校验；失败时保留旧有效值并标记陈旧，不能写入空值或伪造实时数据。

基金权威估值只使用实际业务日期的官方单位净值。累计净值单独保存，不参与持仓市值；第三方估算净值即使恢复，也只能作为可选、明确标记的非权威展示。

## 当日实测

## 决策

### 股票

1. 主数据和首选最新价使用腾讯 A 股榜单接口。
2. 代码前缀 `sh/sz/bj` 只在 Provider 边界映射为 `SSE/SZSE/BSE`，数据库 ticker 不携带供应商前缀。
3. 新浪批量行情只作为已知代码的价格回退，不承担主数据发现。
4. 主数据每日最多一次；行情按活跃持有/自选批量刷新，默认最短间隔 60 秒。

### 基金

1. 主数据使用天天基金公开基金代码脚本，每日最多一次。
2. 官方净值使用开放式基金净值批量页；净值日期来自页面 `showday`，不得改写为抓取日期。
3. 批量源失败时，只对用户活跃基金读取单基金脚本；每只基金每轮最多一次，并设置并发上限 2。
4. 单位净值和累计净值分字段解析，只有单位净值可进入份额推算和权威市值。
5. QDII 等延迟基金始终展示实际净值日期，不显示“今日净值”。

### 估算净值

1. 当前服务器没有通过可达性验证的候选源，因此 `FUND_ESTIMATED_NAV` 默认关闭。
2. 保留数据库价格类型、Provider 契约和页面状态，后续源恢复或获得正式授权时无需破坏契约。
3. 不用官方单位净值外推“估算值”，不以股票持仓自行模拟基金实时估值。
4. Provider 失败时保留旧估算记录并标记陈旧/失败；估算永不进入组合权威汇总。

## 自我限流和失败策略

免费页面没有公开限流承诺，应用采取比页面更保守的自限流：

- 连接超时 5 秒，总请求超时 12 秒；仅对连接错误、429、502、503、504 重试最多 2 次。
- 指数退避 0.5 秒、1.5 秒并加入随机抖动；不重试字段校验错误和其他 4xx。
- 尊重 `Retry-After`；连续失败进入任务失败状态，不循环轰击。
- 股票批次默认不超过 50 个代码；基金单标的回退并发不超过 2。
- 日志只记录来源、任务、计数、异常类型和请求 ID，不记录完整响应、Cookie、用户持仓或令牌。

## 字段漂移边界

所有外部响应先转换为 `ProviderInstrument`、`StockPriceSnapshot`、`FundOfficialNavSnapshot` 或 `FundEstimatedNavSnapshot`。未知字段、缺字段、错误资产交易所组合、非正值、二进制浮点财务值和无时区时间全部拒绝写入。

## 权威性与已知限制

这些是公开页面数据接口，不是付费 SLA 服务，也不构成交易或投资建议。交易所公开列表用于人工抽样核对身份，但一期不在页面请求中直接访问交易所。基金信息披露规则强调净值信息的正式披露边界，因此第三方估算只可作为非权威可选信息。

## 后果

- 优点：当前服务器可达、无需密钥、口径明确、页面无外部 HTTP、可替换 Provider。
- 代价：公开页面字段可能变化；基金估算一期默认不可用；单基金回退响应较大。
- 缓解：固定样本、严格 schema、同步留痕、陈旧标记、保留旧值、显式联网 smoke 与可替换工厂。
